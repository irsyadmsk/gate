# Gate

- Aplikasi mandiri: jalankan perintah dari root repositori ini. Gunakan `npm ci`, `npm test`, dan `npm run build`.
- Pertahankan mobile-first, QR/kartu, serta izin murid yang disetujui pengasuh/piket; satpam memverifikasi dan mencatat.
- Login/RBAC/backend masih terintegrasi dengan Irsyads. Baca `docs/EXTRACTION.md` sebelum mengubah kontrak bersama atau backend.
- Jangan commit `.env`, kredensial server, data sekolah, log akun nyata, backup, atau hasil fixture di `scratch/`.
- Build dan tes lokal bukan bukti alur akun/hardware/produksi. Jangan menjalankan migrasi, deploy, atau mengubah data produksi tanpa instruksi pemilik.
- Jangan menambahkan workflow deploy/Actions otomatis atau biaya baru tanpa instruksi pemilik.
